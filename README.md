# Natural Floor — прогулка по объекту в Самарканде

Второй вариант 3D-прогулки по объекту в Самарканде. В сцене можно пройти вдоль стен, переключить дизайн каменного ковра и выбрать время суток.

Готовая сборка лежит в `public`. Для локального просмотра запустите из корня репозитория:

    python3 -m http.server 8795 --bind 127.0.0.1 --directory public

Откройте http://127.0.0.1:8795. Для пересборки после изменения `src` выполните `npm ci` и `npm run build`.

Маршрут открывает отдельный ракурс каждой стены и каждого откоса. На телефоне доступны кнопки ходьбы и прыжка, свайп для обзора и касание по земле. Чтобы отключить машины, откройте страницу с параметром `?no-cars`.

Мобильное управление проверялось в Chrome с эмуляцией касаний. Положение объекта на карте не подтверждено. Высота высокой стены рассчитана по площади из обмеров. Фотоэскизы из отдельных серий служат референсами и в 3D-сцену не входят.
